# Password Reset Policy

## Policy

Employees may request a password reset through the internal IT portal.

## Procedure

1. Confirm identity via employee ID and registered email.
2. Issue a temporary password that expires in 24 hours.
3. Require password change on first login.
4. Log the action in the security audit trail.

## Escalation

If the account is locked due to suspicious activity, escalate to Security Ops before resetting.
