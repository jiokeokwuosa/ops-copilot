# MFA Reset Runbook

## Overview

Support agents can reset multi-factor authentication (MFA) for employees when a device is lost.

## Steps

1. Verify the requester's identity using the HR directory and a ticket from an approved manager.
2. Open Admin Console → Users → select the employee.
3. Choose Security → Reset MFA.
4. Ask the employee to enroll MFA again on next login.
5. Document the reset in the ticket with timestamp and approver name.

## Notes

- Never reset MFA without manager approval on file.
- Off-topic questions (weather, recipes, celebrity news) are outside support/ops scope.
